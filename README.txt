滨城名师初中英语徐晶工作室 · 网站文件包说明
=================================================

一、文件清单
------------
 index.html      官网首页（给教育局评审看，可点击内容跳转公众号/权威报道）
 manage.html     内容管理后台（发布后管理员进入上传/维护内容、管理公众号链接）
 links.json      链接库：集中维护「首页可点开内容 → 对应网址」的映射
 主持人_徐晶.jpg 主持人工作照
 README.txt      本说明文档

二、如何部署到网站
------------------
方式A（推荐·服务器空间）：
 1. 将全部 5 个文件一起上传到你网站的根目录（或任一子目录）；
 2. 首页地址即 index.html，发布完成。
方式B（本地预览）：
 双击 index.html 可查看版面；但「公众号内容链接」区需部署到服务器
 后才能从 links.json 自动加载（本地打开会提示“请上传服务器”）。

三、怎么进去上传自己的资源
--------------------------
 发布后，访问【网站地址/manage.html】进入内容管理后台，可：
   ① 修改主持人介绍（姓名/简介/荣誉/照片）
   ② 增删主持人及成员介绍
   ③ 增删“活动纪实”记录
   ④ 上传自己的研修资源文件（案例、课件、论文、规划等）
   ⑤ 管理公众号内容链接
 首页页脚有低调的“内容管理入口”可点进去。

四、【重点】怎么让首页内容点开跳转到微信公众号
----------------------------------------------
 首页“可点开的内容”区会自动读取 links.json，把每一条变成
 一个可点击的条目，点击即可打开对应内容。

 要把内容链接到你公众号文章，只需两步：
  第1步：在微信公众号后台，打开目标文章，复制它的“永久链接”
         （形如 https://mp.weixin.qq.com/s/XXXX... ）；
  第2步：把该链接填入 links.json 中对应条目的 "url" 字段
         （也可在 manage.html 的“公众号内容链接管理”里填写），
         保存后重新部署，首页该条目点击即可直达公众号原文。

 links.json 已内置 3 条真实权威报道链接作为示例（半岛晨报、
 大连发布/澎湃、辽宁教育），其余条目（研修案例、讲座等）
 的 url 留空，填入真实公众号文章链接后即可生效。
 首页只展示已填写 url 的条目，url 为空的条目不会显示。

五、给技术老师（后端接入说明）
----------------------------
 当前为【静态网页 + 前端管理界面】，注意事项：
 1. 上传的资源文件目前仅前端显示，未真正存储服务器；
    “保存全部修改”目前是前端演示，未写入服务器；
    如需真正保存，请接入后端（存文件/JSON/数据库）并回显。
 2. 首页与 manage.html 通过 fetch('links.json') 读取链接，
    需部署在服务器（http/https）下才能正常加载；
    本地 file:// 打开会因浏览器安全策略无法读取，属正常现象。
 3. 微信限制：公众号文章链接在 PC/浏览器中打开时，微信可能
    提示“请在微信客户端打开”。如需在网站内顺畅打开公众号内容，
    可选方案：
      a) 引导用户在微信内打开（复制链接）；
      b) 在页面提供“微信打开”引导/二维码跳转；
      c) 使用公众号文章的永久链接配合跳转服务。
 4. 不建议改动首页三个展示板块（主持人/成员/活动纪实）的结构。
