滨城名师初中英语徐晶工作室 · 网站文件包说明
=================================================

一、文件清单
------------
 index.html      官网首页（给教育局评审看的主页）
 manage.html     内容管理后台（发布后管理员进入上传/维护内容）
 主持人_徐晶.jpg 主持人工作照
 README.txt      本说明文档

二、如何部署到网站
------------------
方式A（推荐·服务器空间）：
 1. 将 4 个文件一起上传到你网站的根目录（或任一子目录）；
 2. 首页地址即 index.html，发布完成。
方式B（本地预览）：
 双击 index.html 即可直接用浏览器查看效果（无需联网）。

三、怎么进去上传自己的资源
--------------------------
 发布后，访问【网站地址/manage.html】进入内容管理后台。
 在这里可以：
   ① 修改主持人介绍（姓名/简介/荣誉/照片）
   ② 增删主持人及成员介绍
   ③ 增删"活动纪实"记录
   ④ 上传自己的研修资源文件（案例、课件、论文、规划等）
 首页页脚也有低调的"内容管理入口"可点进去。

四、给技术老师（后端接入说明）
-----------------------------
 当前文件是【静态网页 + 前端管理界面】（manage.html），
 界面上可以选文件、增删内容并"保存"，但：
   · 上传的资源文件目前仅在前端显示，尚未真正存储到服务器；
   · "保存全部修改"目前仅为前端演示，未写入服务器。
 如需"真正保存到服务器并回显到首页"，请在服务端接入：
   1. 提供接口接收文件上传并存储到服务器目录；
   2. 提供接口保存主持人/成员/活动内容（存 JSON 或数据库）；
   3. 首页 index.html 及 manage.html 改为从接口读取数据渲染，
      或由后端直接把数据渲染进 HTML。
 不建议改动现有三个展示板块（主持人/成员/活动纪实）的结构。
